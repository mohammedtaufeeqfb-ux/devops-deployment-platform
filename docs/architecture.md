# Architecture Overview

## Objective

Build a cloud-native deployment platform that automates infrastructure provisioning, application delivery, and monitoring on AWS.

## Components

- Terraform
- GitHub Actions
- Docker
- Amazon ECR
- Amazon EKS
- Helm
- Prometheus
- Grafana

## High-Level Flow

Developer
→ GitHub
→ GitHub Actions
→ Docker Image
→ Amazon ECR
→ Amazon EKS
→ Monitoring Stack
